# Sales Analysis Dashboard – Power BI

Bu projede satış verileri kullanılarak Power BI ile interaktif bir satış ve müşteri analiz dashboard'u oluşturulmuştur.

## 📊 Dashboard

![Sales Analysis Dashboard](images/dashboard.png)

## 🎯 Projenin Amacı

Bu projenin amacı satış verilerini analiz ederek ürün, kategori, müşteri ve bölge bazında satış performansını görselleştirmektir.

## 🛠️ Kullanılan Teknolojiler

- Microsoft Power BI
- Power Query
- Microsoft Excel

## 📌 Analizler

- Toplam satış analizi
- Ortalama satış analizi
- Müşteri sayısı
- Ürün bazlı satış analizi
- Kategori bazlı satış analizi
- Bölgesel satış analizi
- Zaman bazlı satış analizi
- Harita üzerinde satış dağılımı

## 📈 Dashboard İçeriği

Dashboard üzerinde aşağıdaki göstergeler ve görselleştirmeler bulunmaktadır:

- Toplam Satış
- Ortalama Satış
- Müşteri Sayısı
- Ürün bazlı satış tablosu
- Kategori dağılımı
- Bölgesel satış grafiği
- Türkiye satış haritası
- Ay ve yıl bazlı filtreleme

## 📂 Proje Dosyaları

- `SatisAnaliziRaporu.pbix` – Power BI dashboard dosyası
- `satis_verisi.xlsx` – Projede kullanılan veri seti
- `images/dashboard.png` – Dashboard ekran görüntüsü

## 📊 Veri Seti

Bu projede kullanılan veri seti eğitim ve portföy amaçlı kullanılmıştır.

## 🚀 Sonuç

Power BI kullanılarak satış verilerinin farklı boyutlarda analiz edilmesini sağlayan interaktif bir dashboard oluşturulmuştur.
